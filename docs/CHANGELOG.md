# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added
- Created `docs/UI_UX_STANDARDS.md` to define mandatory UI/UX standards for both Client and Admin applications.
- Established "Strict Shadcn-only" rule for all UI development.
- Standardized touch target size to 44px (Apple HIG) across the entire platform.
- Enforced `rounded-full` styling for all primary interactive elements.

### Changed
- Updated `docs/GEMINI.md` to point to the new UI/UX standards.
- Synchronized Admin UI principles with Client UI expectations for end-to-end consistency.

### Fixed
- Identified UI/UX gaps between Admin and Client roles, specifically regarding component duplication and inconsistent sizing.
